# Mobile Order UI Simulator

卒業研究用のモバイルオーダーUIシミュレータです。

## 目的

加齢による視覚の黄変化が、モバイルオーダーUIの配色と使いやすさに与える影響を調査するための実験環境を作成します。

## 実験条件

- パステルカラー系配色 × 黄変化なし
- パステルカラー系配色 × 黄変化あり
- 高コントラスト配色 × 黄変化なし
- 高コントラスト配色 × 黄変化あり

## 設計方針

- 配色を設定ファイルから変更できるようにする
- 黄変フィルタを設定ファイルから変更できるようにする
- 画面構成や注文フローを後から調整しやすくする
- 操作ログを後から分析しやすい形で記録する
