# Experiment Notes

実験設計、条件変更、アンケート項目、操作ログ項目などを整理するためのメモです。

## 実験用受付番号

有効な `task`、`color`、`yellow` がそろった実験アクセスでは、注文成立時に次の形式で受付番号を生成する。

`[正誤][条件][タスク]-[操作時間]-[総タップ数]-[誤選択回数]-[戻る回数]`

例：`TA1-065-024-01-02`

- 正誤は、最終注文が正解なら `T`、不正解なら `F`。
- 条件 `A` はパステル・黄変化なし。
- 条件 `B` はパステル・黄変化あり。
- 条件 `C` は高コントラスト・黄変化なし。
- 条件 `D` は高コントラスト・黄変化あり。
- タスクは `1` から `4`。
- 操作時間は内部ではミリ秒のまま保持し、受付番号の生成時に秒へ換算して四捨五入する。最低3桁で0埋めする。
- 総タップ数は最低3桁、誤選択回数と戻る回数は最低2桁で0埋めする。
- 最低桁数を超えた値は切り捨てず、そのまま必要な桁数で出力する。
- 数字部分は固定位置ではなく、ハイフン区切りで解釈する。
- 商品の正誤判定は商品IDとオプションIDを使用し、表示順には依存しない。
